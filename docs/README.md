Sudoku — Project Plan

1. Project Overview 
    Project Type: Browser-Based Game
    Description: A responsive, browser-based Sudoku game that can be played on laptops, desktops, tablets, and mobile devices.
        -Html5.
        -Css3.
        -Javascript (Vanilla Js).
2. Project Objectives 
    The primary objective is to develop an interactive Sudoku game that provides users with an enjoyable puzzle-solving experience across different devices.
        -Implementing Sudoku puzzle generation algorithms.
        -Developing a Sudoku-solving and validation system.
        -Creating a responsive and intuitive user interface.
        -Practicing JavaScript programming and problem-solving.
        -Implementing browser-based data persistence.
3. Core Features 
        -Sudoku Board with 81 cells 9 rows and 9 columns.
        -Prefilled Numbers and empty Cell. 
        -Highlight Cells.
        -Generate Randommized Valid Sudoku solution.
        -Ensure Generated puzzles have exactly one solution. 
        -Start new game.
        -Erase selected cell.
        -Pause and Resume. 
        -Game timer.
        -Erase counter. 
        -Store Basic Game stats like games played and best game. 
        -Dark and light themes.

4. Game Levels 
    Easy Sudoku 
        - More Starting Numbers
        - Zero Restrictions on Erasing 
        - Straightforward cell wise missing number detection
    Medium Sudoku
        -Fewer Starting Numbers 
        -Only Rows and Col wise duplicate detection
        -Limited Number of Erasing
    Hard Sudoku 
        -Very Few Starting Numbers
        -Zero Number of Erasing 
        -No Duplicate Detection
